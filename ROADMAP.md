# Food Recognition 🥗 — Пошаговый план проекта

## Цель проекта
Создать систему распознавания еды по фотографии с автоматической оценкой веса ингредиентов и расчетом КБЖУ, возможностью ручной корректировки и ведением дневника питания. Проект строится по принципу **«Один бэкенд — два клиента»**: **PWA (веб)** и **Android-приложение (Flutter)**.

---

## Архитектура системы

```
[ 1. Веб / PWA ] ─────> [ Бэкенд (Python / FastAPI) ] <───── [ 2. Android-приложение (Flutter) ]
                              │
                    ┌─────────┴─────────┐
                    ▼                   ▼
          [ Google Gemini Vision ]  [ База данных SQLite ]
          (Распознавание и КБЖУ)    (Дневник и история)
```

---
