# Food Recognition 🥗

Система распознавания еды по фотографии с автоматической оценкой веса ингредиентов и расчетом КБЖУ.

## Архитектура
Проект строится по принципу **«Один мозг — три интерфейса»**:
- **Telegram-бот**: быстрый ввод и распознавание блюд на ходу через мессенджер.
- **PWA (Веб-интерфейс)**: просмотр дневника, календарь и детальное редактирование.
- **Android-приложение (Flutter)**: мобильное приложение с диаграммами дневной нормы КБЖУ.
- **Бэкенд (Python / FastAPI)**: единый сервис с базой SQLite и интеграцией с Google Gemini Vision.
