# Food Recognition 🥗

Система распознавания еды по фотографии с автоматической оценкой веса ингредиентов и расчетом КБЖУ.

## Архитектура
Проект строится по принципу **«Один бэкенд — два клиента»**:
- **PWA (Веб-интерфейс)**: просмотр дневника, календарь, ручной ввод и детальное редактирование.
- **Android-приложение (Flutter)**: нативное мобильное приложение с диаграммами дневной нормы КБЖУ, камерой и автообновлением.
- **Бэкенд (Python / FastAPI)**: единый сервис с базой SQLite и интеграцией с Google Gemini Vision.

## Мобильное приложение для Android (APK)
Готовый установочный файл **`myfooddiary.apk`** собирается автоматически в облаке GitHub Actions:
- **Скачать релиз**: перейдите во вкладку [Releases](https://github.com/AnikaBu/Food_recognition/releases) репозитория и загрузите файл `myfooddiary.apk` прямо на смартфон.
- **Подключение**: в настройках мобильного приложения укажите локальный адрес вашего бэкенда (например, `http://192.168.1.100:8000`) или облачный URL.

## Быстрый запуск
Запуск сервера (бэкенд API + веб-клиент PWA) одной командой из любого места в терминале:
```bash
food
```
*(симлинк настроен в `~/.local/bin/food`)*

Либо из папки проекта:
```bash
./run.sh
```
Для остановки сервера нажмите `Ctrl+C` в окне терминала.
