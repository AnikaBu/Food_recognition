# Food Recognition 🥗

Система распознавания еды по фотографии с автоматической оценкой веса ингредиентов и расчетом КБЖУ.

## Архитектура
Проект строится по принципу **«Один мозг — три интерфейса»**:
- **Telegram-бот**: быстрый ввод и распознавание блюд на ходу через мессенджер.
- **PWA (Веб-интерфейс)**: просмотр дневника, календарь и детальное редактирование.
- **Android-приложение (Flutter)**: мобильное приложение с диаграммами дневной нормы КБЖУ.
- **Бэкенд (Python / FastAPI)**: единый сервис с базой SQLite и интеграцией с Google Gemini Vision.

## Мобильное приложение для Android (APK)
Готовый установочный файл **`food-recognition.apk`** собирается автоматически в облаке GitHub Actions:
- **Скачать релиз**: перейдите во вкладку [Releases](https://github.com/AnikaBu/Food_recognition/releases) репозитория и загрузите файл `food-recognition.apk` прямо на смартфон.
- **Подключение**: в настройках мобильного приложения укажите локальный адрес вашего бэкенда (например, `http://192.168.1.172:8000`) или облачный URL Google Cloud.

## Быстрый запуск
Запуск всех сервисов (веб-приложение PWA + Telegram-бот) одной командой из любого места в терминале:
```bash
food
```
*(симлинк настроен в `~/.local/bin/food`)*

Либо из папки проекта:
```bash
./run.sh
```
Для остановки всех сервисов нажмите `Ctrl+C` в окне терминала.
